# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-09-05

### Added
- Core PDF text extraction with position tracking
- Advanced OCR support for scanned documents
- Table and structured data extraction
- Metadata extraction (title, author, creation date, etc.)
- Link and URL extraction from PDF documents
- Comprehensive data validation system
- Multi-language support (Arabic and English)
- JSON export with complete metadata
- Command-line interface
- Unit test suite
- CI/CD pipeline with GitHub Actions

### Features
- Text Extraction with position information
- OCR Support for scanned documents
- Table Detection and extraction
- Metadata Handling
- Validation with detailed reports
- Error Handling and logging
- Cloud Ready deployment
